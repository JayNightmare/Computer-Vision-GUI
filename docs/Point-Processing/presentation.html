1 · Theory

Retinex model & human perception

The Retinex Model

Retinex = retina + cortex  (Land, 1977)

An observed image is decomposed into two components:

I(x, y)  =  R(x, y)  ×  L(x, y)
Component Symbol Meaning
Reflectance R(x, y) Intrinsic surface colour, independent of lighting
Illumination L(x, y) Scene lighting — varies slowly across space

Goal: estimate and remove the illumination → reveal true appearance.

Single-Scale Retinex (SSR)

Estimate illumination via Gaussian blur; work in log-space to convert multiplication → subtraction:

Rssr(x, y) = log( I(x, y) ) − log( Gσ ∗ I(x, y) )

Small σ

Preserves fine detail but poor dynamic-range compression

Large σ

Strong dynamic-range compression but may lose local contrast

Multi-Scale Retinex (MSR)

Averages SSR results across multiple scales to balance both needs:

Rmsr(x, y) = (1/N)  Σ  [ log( I ) − log( Gσₙ ∗ I ) ]

Typical scale triplet: σ = 15 σ = 80 σ = 250  (Jobson et al., 1997)

Result: good local contrast and good dynamic-range compression.

SSR — Implementation

def single_scale_retinex(image: np.ndarray, sigma: float) -> np.ndarray:
    """Apply Single-Scale Retinex to an image."""
    blurred = cv2.GaussianBlur(image, (0, 0), sigma)
    retinex = np.log10(image + _EPSILON) - np.log10(blurred + _EPSILON)
    return retinex
  • _EPSILON = 1.0 prevents log(0)
  • Kernel size (0, 0) lets OpenCV auto-compute from σ
  • Returns log-space result — needs normalisation before display

MSR — Implementation

def multi_scale_retinex(
    image: np.ndarray,
    sigmas: list[float] | None = None,
) -> np.ndarray:
    """Average SSR results across multiple Gaussian scales."""
    if sigmas is None:
        sigmas = [15.0, 80.0, 250.0]

    retinex = np.zeros_like(image, dtype=np.float64)
    for sigma in sigmas:
        retinex += single_scale_retinex(image, sigma)

    retinex /= len(sigmas)
    return retinex

Composes SSR at each scale then averages — simple yet effective.

Human Perception & Lightness Constancy

Human vision exhibits lightness constancy — perceiving a surface's colour as roughly the same under varying illumination.

Example

A white sheet looks "white" both indoors under tungsten light and outdoors in daylight — even though the wavelengths differ dramatically.

Why Retinex Works

The visual system estimates illumination and "divides it out", leaving perceived reflectance — exactly what the algorithm does mathematically.

Retinex mimics this perceptual normalisation — enhanced images look more natural because they model what our eyes already do.

Strengths & Limitations

✓ Strengths

  • Enhanced detail in shadows
  • Dynamic-range compression (HDR-like)
  • More natural, perceptually pleasing colour

✗ Limitations

  • Halo artefacts near strong edges
  • Colour distortion without MSRCR
  • Computational cost for large σ kernels
  • Parameter sensitivity (σ tuning)

Brightness & Contrast

Brightness

g(x,y) = f(x,y) + β
def adjust_brightness(image, beta):
    return cv2.convertScaleAbs(
        image, alpha=1.0, beta=beta
    )

β range: −100 … +100

Contrast

g(x,y) = α · f(x,y)
def adjust_contrast(image, alpha):
    return cv2.convertScaleAbs(
        image, alpha=alpha, beta=0
    )

α range: 0.5 … 3.0

Gamma Correction

O = (I / 255)1/γ × 255 
def gamma_correction(image, gamma):
    if gamma <= 0:
        gamma = 0.01
    inv_gamma = 1.0 / gamma
    table = np.array(
        [((i / 255.0) ** inv_gamma) * 255 for i in range(256)],
        dtype=np.uint8,
    )
    return cv2.LUT(image, table)

γ < 1 → Brighten

Boosts dark regions, expands shadows

γ > 1 → Darken

Compresses highlights, deepens tones

Histogram Equalization & CLAHE

Global Equalization

def histogram_equalization(image):
    ycrcb = cv2.cvtColor(
        image, cv2.COLOR_BGR2YCrCb
    )
    ycrcb[:, :, 0] = cv2.equalizeHist(
        ycrcb[:, :, 0]
    )
    return cv2.cvtColor(
        ycrcb, cv2.COLOR_YCrCb2BGR
    )

Equalises luminance (Y channel) only — preserves colour chrominance.

CLAHE

def apply_clahe(image,
    clip_limit=2.0,
    tile_grid_size=(8, 8)):
    clahe = cv2.createCLAHE(
        clipLimit=clip_limit,
        tileGridSize=tile_grid_size
    )
    ycrcb = cv2.cvtColor(
        image, cv2.COLOR_BGR2YCrCb
    )
    ycrcb[:, :, 0] = clahe.apply(
        ycrcb[:, :, 0]
    )
    return cv2.cvtColor(
        ycrcb, cv2.COLOR_YCrCb2BGR
    )

3 · Histograms

Per-channel computation & visual comparison

Histogram Computation

def compute_histogram(image: np.ndarray) -> dict[str, np.ndarray]:
    """Compute per-channel histograms for BGR or grayscale image."""
    if image.ndim == 2:
        hist = cv2.calcHist([image], [0], None, [256], [0, 256])
        return {"gray": hist.flatten()}

    channels = {"b": 0, "g": 1, "r": 2}
    result: dict[str, np.ndarray] = {}
    for name, idx in channels.items():
        hist = cv2.calcHist([image], [idx], None, [256], [0, 256])
        result[name] = hist.flatten()
    return result

def _draw_histogram(self, img, ax, canvas, title):
    ax.clear()
    self._style_axis(ax, title)

    hist_data = compute_histogram(img)

    if "gray" in hist_data:
        ax.plot(hist_data["gray"], color="#cdd6f4",
                linewidth=1.2, alpha=0.85)
    else:
        for channel, color in _HIST_COLORS.items():
            ax.plot(hist_data[channel], color=color,
                    linewidth=1.2, alpha=0.85)

    ax.set_xlim([0, 256])
    canvas.draw_idle()

Processing Pipeline

def _compute_altered(self):
    img = self.app.original_image.copy()

    if brightness != 0:
        img = adjust_brightness(img, brightness)
    if contrast != 1.0:
        img = adjust_contrast(img, contrast)
    if gamma != 1.0:
        img = gamma_correction(img, gamma)
    if self._equalized:
        img = histogram_equalization(img)
    if self._grayscale:
        img = cv2.cvtColor(
            img, cv2.COLOR_BGR2GRAY
        )

    return img

Image Display Logic

def _show_image(self, img, canvas, is_original):
    canvas.update_idletasks()
    cw = max(canvas.winfo_width(), 200)
    ch = max(canvas.winfo_height(), 200)

    h, w = img.shape[:2]
    scale = min(cw / w, ch / h, 1.0)   # fit, never upscale
    new_w, new_h = int(w * scale), int(h * scale)

    if img.ndim == 2:         # grayscale
        display = img
    else:                     # BGR → RGB
        display = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

    resized = cv2.resize(display, (new_w, new_h),
                         interpolation=cv2.INTER_AREA)
    pil_img = Image.fromarray(resized)
    photo = ImageTk.PhotoImage(pil_img)

    canvas.delete("all")
    canvas.create_image(cw // 2, ch // 2,
                        anchor=tk.CENTER, image=photo)

def save_results(original, enhanced, output_dir, filename_stem, mode="msr"):
    output_path = Path(output_dir)
    output_path.mkdir(parents=True, exist_ok=True)

    enhanced_path = output_path / f"{filename_stem}_{mode}_enhanced.jpg"
    comparison_path = output_path / f"{filename_stem}_{mode}_comparison.png"

    cv2.imwrite(str(enhanced_path), enhanced)
    fig = create_comparison(original, enhanced, ...)
    fig.savefig(str(comparison_path), dpi=150, bbox_inches="tight")

Comparison Visualisation

def create_comparison(original, enhanced, title="Retinex Enhancement"):
    original_rgb = cv2.cvtColor(original, cv2.COLOR_BGR2RGB)
    enhanced_rgb = cv2.cvtColor(enhanced, cv2.COLOR_BGR2RGB)

    fig, axes = plt.subplots(1, 2, figsize=(14, 6))
    fig.suptitle(title, fontsize=16, fontweight="bold")

    axes[0].imshow(original_rgb)
    axes[0].set_title("Original")
    axes[0].axis("off")

    axes[1].imshow(enhanced_rgb)
    axes[1].set_title("Enhanced (Retinex)")
    axes[1].axis("off")

    fig.tight_layout()
    return fig

Caller decides whether to display interactively or save to disk — clean separation.
